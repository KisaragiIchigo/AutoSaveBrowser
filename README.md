# AutoSaver Next (URLSaver Remake)

Web上のリサーチ資料や記事、画像、技術ドキュメントを、Ctrl+クリックでバックグラウンド高速完全保存し、完了後に自動クローズする **USBポータブル対応 Webアーカイブブラウザ** です。

---

## 🌟 主な特徴

1. **完全ポータブル設計（USBメモリ対応）**
   - 実行ファイル（またはプロジェクト）直下の `portable_data/` フォルダ内で、設定・Cookie・ログインセッション・ブックマーク・保存先がすべて自己完結。
   - 他のPCのUSBポートに挿すだけで、パスの再設定なしに即座に利用可能。
2. **洗練された北欧風スレート＆セージミント（Nordic Slate & Sage）UI**
   - ギラつくダークアクリルや安易な紫グラデーションを排除し、プロフェッショナルな計器のようなマットな質感と極細ヘアラインボーダーを採用。
3. **直感的な SaveMode（自動保存モード）**
   - **SaveMode ON** にしてリンクを `Ctrl+クリック`（または中クリック）すると、新規タブがバックグラウンドで開き、読み込み完了後に Chromium ネイティブの最高精度で完全保存（HTML+画像CSS等 / MHTML / PDF）。
   - 保存が完了したら、そのバックグラウンドタブは自動でクローズされます。
4. **可視化された保存キュー ＆ アーカイブ履歴サイドパネル**
   - バックグラウンドで進行中のタスク件数や、保存済みファイル一覧（タイトル、ドメイン、ファイルサイズ、保存日時）をリアルタイムに確認可能。
   - 保存フォルダを開くボタン、ファイルを開くボタンも完備。
5. **高速広告ブロック (EasyList + EasyPrivacy + 手動ブロック)**
   - 初回起動時に自動ダウンロード＆手動更新可能。不要な広告やトラッカーを遮断して高速保存。
6. **ドメイン別自動仕分け＆タイムスタンプ**
   - `保存先/ドメイン名/ページ名.html` に自動整理。連番重複回避（` (2)`, ` (3)`）にも対応。

## 🚀 ワンクリック起動 / コンパイル / 公開

プロジェクトルートに配置されたバッチファイルをダブルクリックするだけで実行できます。

| バッチファイル | 動作 |
| :--- | :--- |
| **`起動テスト.bat`** | 開発モードでアプリを即座に起動して動作テストを行います。 |
| **`コンパイル.bat`** | TypeScript型チェック・Viteビルドを実行し、**`release/` フォルダに単体ポータブルEXE（`AutoSaverNext 1.0.0.exe`）** を出力します。 |
| **`githubpush.bat`** | GitHub リポジトリ（`KisaragiIchigo/AutoSaveBrowser`）へソース一式をコミット・プッシュします。初回実行時はリポジトリ初期化とコミット者情報の設定も自動で行います。 |


> **公開時の安全装置について**
> `portable_data/`（Cookie・ログインセッション・保存履歴）、`node_modules/`、`release/`、`dist/` は `.gitignore` で除外されています。`githubpush.bat` は実行前に `portable_data` が除外対象であることを検証し、除外されていない場合はプッシュを中止します。

---

## 📂 生成されたポータブルEXEの配布

コンパイル完了後、**`release/AutoSaverNext 1.0.0.exe`** をUSBメモリや好きなフォルダにコピーして実行するだけで、そのまま設定なしで完全ポータブル運用できます。

---

## ⌨️ 主なショートカットキー

- `Ctrl + T`: 新しいタブを開く
- `Ctrl + W`: 現在のタブを閉じる
- `Ctrl + L`: アドレスバーにフォーカス
- `Ctrl + D`: 現在のページをブックマーク
- `Ctrl + S`: 現在のページを今すぐ保存
- `Ctrl + Shift + S`: SaveMode（自動保存）のON/OFF切り替え
- `Ctrl + H`: 保存キュー＆アーカイブ履歴パネルの開閉
- `Ctrl + R`: ページの再読み込み
